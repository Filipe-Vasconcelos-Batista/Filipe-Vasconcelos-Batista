# Hi, I'm Filipe 👋

Software developer, coding since 2020. I build Python backends and data pipelines and run
them on Azure, and I work on distributed systems. Before that I built web apps with
Symfony and Vue, and before that I worked in industrial management.

## What I work on

- **Large-scale data pipelines**: daily collection of catalog, pricing and inventory data
  from web and mobile channels (~200k+ rows/day across ~1,750 locations), with
  DB-coordinated async workers, a shared circuit breaker, and ETL into PostgreSQL and
  cloud storage.
- **Production operations on Azure**: VMs, Azure Database for PostgreSQL, Blob Storage,
  and scheduled Azure DevOps pipelines on self-hosted agents.
- **Backend performance**: as a Symfony developer I added a caching layer in front of
  tables with 8M+ rows, which cut query load by 75% and lowered AWS costs. I also
  migrated the app from Symfony 3.4 to 4.4.
